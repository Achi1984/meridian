# ACHI MERIDIAN v5.24.8 — Watchlist Priority

Neu:
- WATCHLIST wird automatisch priorisiert:
  - READY WHEN UNLOCKED
  - WAIT FOR TRIGGER
  - WATCH
  - IGNORE
- Ranking basiert auf Signalbasis, Setup, Entry, Intelligence und R:R.
- Gute Setups bleiben sichtbar, obwohl das Capital Gate blockiert.
- Sobald das Capital Gate öffnet, fällt die Watchlist-Klassifizierung weg und normale Entry-Entscheidungen greifen.
- Keine automatische Order-Ausführung.
