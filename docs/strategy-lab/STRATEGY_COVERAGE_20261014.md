## Required assessment for every row

1. Recover existing implementation, prior trials and failures with pinned source evidence. Unknown history stays unknown.
2. Define one reproducible initial hypothesis: inputs, parameters, confirmation/availability time, direction, entry, invalidation, exit, sizing and applicable costs. Sketches below are questions to resolve, not frozen executable specifications.
3. Compare against a predeclared simple control on identical eligible data and execution assumptions. Change one feature at a time before testing combinations. Record all manual variants and failed attempts; no favorable sample or parameter selection after results.
4. Check causal synthetic fixtures and data suitability first. Empirical work requires the reconciled trial budget, frozen manifest and existing execution/review gates. Owner interest in all concepts establishes assessment scope; it does not make an unprepared historical run reviewable.
5. When authorized, report net results, drawdown, turnover, exposure, sample dependence and regime stability. Inspected data remain development data. Any independent validation requires genuinely unseen or prospectively collected observations.
6. End with a source-backed disposition: SPECIFIABLE, DATA_BLOCKED, REDUNDANT, EMPIRICALLY_UNSUPPORTED or FURTHER_VALIDATION_REQUIRED. A design assessment cannot use the empirical disposition without actual evidence. No automatic promotion or trading.
